# AlouCar App

Sistema de agendamento e monitoramento de serviços automotivos.

# Getting Started

### Requisitos
- .NET 8.0
- SQL Server Express

### Como rodar

1. Clone o repositório
2. Execute as migrations:

   cd alouCarApp.Repositorio
   dotnet ef database update

3. Execurta o projeto:

   dotnet run --project alouCarApp.API


# Build and Test


dotnet build
